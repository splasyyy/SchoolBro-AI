# **SchoolBro AI: An Intelligent School Assistant**

**SchoolBro AI** is an AI-powered virtual assistant designed to help students by providing useful features such as answering questions, offering motivational messages, translating text, and comparing academic results. Built using OpenAI’s GPT models, SchoolBro AI offers a seamless, interactive experience that can assist students in various educational tasks.

## **Features**

- **Answering Questions**: SchoolBro AI can answer a wide range of questions, offering detailed and contextually relevant responses based on user input.
  
- **Motivational Messages**: Need encouragement? SchoolBro AI can provide motivational quotes and messages to help students stay inspired and motivated.

- **Text Translation**: SchoolBro AI can translate text into different languages, making it a handy tool for language learning.

- **Comparison of Results**: Compare different academic results and receive insightful feedback about your progress.

- **Interactive Command Interface**: Users interact with SchoolBro AI through a simple text-based interface, receiving immediate responses.

## **How It Works**

SchoolBro AI uses **OpenAI's GPT-3/4 API** to generate natural language responses. The assistant processes user input, interprets the intent, and then responds with relevant information, whether that’s an answer to a question, a translation, a motivational message, or a comparison of results.

- **Powered by OpenAI's GPT-3/4**: The assistant sends the user’s input to OpenAI's language model and retrieves a generated response. The AI’s advanced capabilities make it adept at handling a wide variety of tasks in natural language.
  
- **Text-Based Interface**: The interaction is handled via a simple command-line interface, where users can enter commands, ask questions, or request specific features, and receive AI-generated responses in return.

## **Getting Started**

### Prerequisites

To run **SchoolBro AI**, you need the following:
- Python 3.x
- An OpenAI API Key

### Installation Steps

1. **Clone the Repository**:  
   Clone or download this repository to your local machine.
   ```bash
   git clone https://github.com/your-username/SchoolBro-AI.git
   
2. **Install Dependencies:**:  
   Install the required Python libraries:
   ```bash
   pip install openai

3. **Set up OpenAI API Key:**:  
   You need to set your OpenAI API key. If you don’t have an API key yet, you can get it from OpenAI. Once you have it, place it in the api_key variable in the script or configure it via environment variables.

4. **Run SchoolBro:**:  
In your terminal, navigate to the project directory and run:
   ```bash
   python main.py

  5. **Interact with the Assistant:**:  
  Follow the on-screen instructions to interact with the AI assistant. You can ask questions, request translations, or ask for motivational quotes!


### Example Commands

- **Ask a question**:  
  `What is the capital of France?`
  
- **Request a motivational message**:  
  `Motivate me!`
  
- **Translate text**:  
  `Translate "Bonjour" to English`
  
- **Compare results**:  
  `Compare 85% and 90%`
### Exiting The Programm

To exit the program, simply type `exit` at the command prompt.
